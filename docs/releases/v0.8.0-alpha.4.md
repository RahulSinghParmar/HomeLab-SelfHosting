# 0.8.0-alpha.4 — Encrypted code-server production migration

This prerelease adds a strict migration plan/evidence contract and records the successful reference Windows production cutover.

## Delivered

- Restic 0.19.1 archive/executable checksum lock dedicated to the code-server module.
- Deterministic nonexecuting migration policy with ordered backup, restore, rollback and public-health gates.
- Stopped-state encrypted snapshot of all four persistence scopes plus Compose/build metadata.
- Full repository-data check and independent restored 4.145.0/Node 24.19.0 compile/restart proof.
- Production migration from the mismatched 4.131.0 binary to exact 4.145.0 while preserving mounts and resource limits.
- Loopback-only direct port, local/public HTTP 200 after Compose restart, plaintext cleanup and retained rollback assets.
- Eight focused migration tests, Phase 7 validation, runbook and evidence record.

## Not claimed

- Off-machine repository storage or offline recovery-key custody.
- Authenticated browser autosave/reconnect or public WebSocket proof.
- Automatic migration of another user's production workspace.
- arm64 runtime certification.

Production remained healthy after the completed cutover.
