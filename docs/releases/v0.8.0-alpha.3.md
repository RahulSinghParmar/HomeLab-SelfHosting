# 0.8.0-alpha.3 — Coolify existing-instance adapter

This prerelease adds a bounded read-only adapter for the existing Coolify deployment on Windows Docker Desktop.

## Delivered

- Strict seven-component policy with explicit root Compose, generated proxy and scheduler-managed Sentinel ownership.
- Sanitized live audit of image identity, health, port bindings, privilege and Docker-control boundaries.
- Root/proxy Compose and dashboard health checks plus local control-plane backup classification.
- Hash-bound planning that has no apply operation, does not adopt production state and keeps update-readiness blocked.
- Focused tests, Phase 7 validation, runbook and live evidence record.

## Not claimed

- Upstream-supported or high-availability Windows hosting.
- Fresh Coolify installation or ownership of generated resources.
- Automatic updates or safe image-only downgrade after database migration.
- Encrypted off-host control-plane recovery.
- Recovery of applications, databases or volumes managed through Coolify.

The live instance stayed healthy and unchanged throughout validation.
