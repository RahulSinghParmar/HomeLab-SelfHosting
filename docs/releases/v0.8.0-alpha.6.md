# 0.8.0-alpha.6 — Explicit Docker update management

This prerelease adds a central operator-controlled update workflow without introducing unattended container replacement.

## Delivered

- Read-only Compose/container inventory across the current Docker context.
- Optional registry digest comparison without pulling images.
- Remote OCI version/revision inspection for proposed targets.
- Exact one-service plans bound to current Compose and image evidence.
- Rolling-tag, repository-switch, controller-ownership and missing-backup refusals.
- Stopped application-path backup copies with hash verification.
- Single-service image pinning, Compose validation, health checks, update locks and recovery journals.
- Focused unit tests, CLI integration, policy example and operator guide.
- Sanitized Windows reference-host and ARR update evidence.

## Not claimed

- Automatic whole-host updates or unattended schedules.
- Generic database-major-version migration safety.
- Recovery readiness for any service lacking its own application-consistent backup rule.
- Control of Coolify-generated projects, local builds or one-shot migration jobs.
- Linux/macOS live apply evidence or arm64 runtime evidence.
- Automatic downgrade after a possible data migration.

The manager is suitable for explicit reviewed updates. Stable production adoption remains service-specific and depends on successful restore drills, not only successful image replacement.
