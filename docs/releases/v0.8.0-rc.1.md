# 0.8.0-rc.1 — Integrated Phase 7 candidate

Released 2026-11-19.

This candidate integrates the Phase 7 code-server, Matrix/Element, Coolify, Docker update and native Windows lifecycle contracts. The new native adapter audits Windows services, interactive startup entries, Scheduled Tasks, Docker Desktop, private Glances and five dashboard samples without persisting secrets, local paths or raw metrics.

Reference-host validation corrected ArrStack backup catch-up behavior and made Task Scheduler directly own the Glances Python process. A repeated controlled monitoring restart passed, and the final current-boot audit had no blockers.

This remains a release candidate rather than stable `0.8.0`. The current boot proves observed recovery, but the stronger checkpoint-before/reboot/check-after sequence still requires an owner-controlled Windows restart. The repository provides that workflow and explicitly never initiates the reboot itself. Optional TURN remains disabled unless its independent relay and real-call gates pass, and the Coolify controller continues to block unsafe updates rather than treating them as Phase 7 failures.
