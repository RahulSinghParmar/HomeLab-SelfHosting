# 0.8.0-alpha.8 — Coolify controller portability correction

Released 2026-11-18.

This candidate contains the complete alpha.7 Coolify controller integration and one bounded portability correction. The policy intentionally stores the reviewed Windows custom-Compose locator with backslashes. Alpha.7 joined that string directly with `Path`, which works on Windows but treats the backslash as an ordinary filename character on Linux and macOS.

Alpha.8 parses that locator as `PureWindowsPath` and then joins its individual parts to the platform-local root. The same public test now verifies Reverb-boundary detection on every CI operating system.

No live Coolify configuration, container, image, backup, task, policy decision or update blocker changed. The reference instance remains healthy on 4.5.3, and 4.7.5 remains unavailable for execution until encrypted off-host recovery, read-only API visibility and the Soketi-to-Reverb rehearsal pass.
