# 0.1.0 — Blueprint foundation

Initial public foundation for a selectable, recoverable self-hosting toolkit based on a working Windows homelab.

## Included

- A sanitized 21-module catalog and read-only reference inventory.
- Architecture for platform adapters, independent Compose projects, storage selection, secret isolation and owned-state execution.
- Ten implementation phases after the foundation, with acceptance gates and copy-paste prompts.
- Recovery design, service-specific runbook requirements and public-access guidance.
- Three example design plans, structural validator, regression tests and static CI.

## Not included

No installer, application templates, production migration, backup engine, restore engine, GPU provisioning, DNS changes or native-host changes. Examples are non-executable design fixtures. No live application data or credentials are bundled.

## Validation scope

Run `python tools/validate_repository.py` and `python -m unittest discover -s tests -v` from the checkout. CI exercises those static checks on Windows, Ubuntu and macOS using Python 3.12 and 3.14. A passing CI run does not certify application deployment on those platforms.

Phase 1 is next: evidence-backed configuration extraction and individual application runbooks.
