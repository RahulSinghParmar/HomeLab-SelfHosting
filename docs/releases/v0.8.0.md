# 0.8.0 — Phase 7 complete

Released 2026-11-23.

This release completes the declared Phase 7 development, communication, controller and native-host scope. It retains the pinned code-server toolchain and encrypted migration, Matrix identity/recovery and optional-integration gates, the non-owning Coolify controller handoff, and explicit backup-gated Docker update management.

The final gate was an actual Windows reboot. A checkpoint from the prior boot was compared with the 2026-11-23 boot: task-definition fingerprints and Glances configuration hashes persisted, and automatic services, interactive startup, all declared Scheduled Tasks, Docker Desktop, private Glances and five dashboard samples recovered.

The first post-reboot audit correctly failed on a stale storage sample and a failed AFFiNE daily backup. The storage parser was made safe for pending recovery metadata, and AFFiNE content counts now occur after application quiescence. A real scheduled backup then passed its restore test and returned the application healthy; the repeated reboot proof passed with no blockers.

Optional TURN remains disabled without external authenticated relay plus real-call evidence. Coolify updates remain blocked when recovery, active-deployment visibility or migration gates are absent. Stable Phase 7 does not convert those deliberate no-go decisions into false support claims.
