# 0.8.0-alpha.1 — Phase 7 code-server foundation

This prerelease starts Phase 7 with a reproducible development-environment candidate.

## Included

- Immutable code-server `4.145.0` amd64/arm64 base identity.
- Architecture-correct Node `24.19.0` downloads with official checksums.
- Broad server-side toolchains and 18 pinned extensions.
- Copy-once autosave, session, terminal and local-history defaults.
- Loopback-only, capability-dropped, resource-bounded Compose rendering.
- Deterministic plans, tamper checks and sanitized evidence validation.
- An amd64 Windows Docker Desktop compile, recreation, stopped-backup and independent-restore proof.

## Production decision

The existing service remains unchanged and healthy. Its image tag claims `4.144.0` while the binary is `4.131.0`; migration is intentionally blocked until encrypted production backup, rollback and real client/WebSocket checks are complete.

## Not yet included

- Production code-server cutover or public-domain changes.
- Byte-identical APT repository snapshots.
- arm64 runtime execution.
- Matrix, Coolify or Windows reboot/startup implementation.
- Phase 7 stable-release closure.

This is a prerelease. Continue with the Matrix identity/recovery module, Coolify adapter and native Windows lifecycle gates before `0.8.0`.
