# 0.7.0-alpha.5 — Jellyfin application recovery and direct play

Date: 2026-11-10

## Included

- A disposable native-Windows Jellyfin 12.4 recovery rehearsal using only generated credentials and synthetic media.
- Jellyfin built-in online backup with database, configuration, metadata, subtitles and trickplay selected.
- ZIP integrity and required Jellyfin 12 JSON database-export validation.
- Source-state deletion followed by initialization of an unrelated same-version target and `--restore-archive` recovery.
- Byte-exact static direct play before backup, after restore and after a full recovered-instance restart.
- A strict reusable evidence validator exposed through `jellyfin validate-recovery`.
- Fail-closed port, path, confirmation, production-use, GPU and transcode boundaries.

## Reference result

The Windows rehearsal passed with Jellyfin 12.4.0. The application archive contained 46 valid entries, the independent target restored successfully, and all three direct-play responses returned the same 11,323-byte MP4 and SHA-256. The production service stayed healthy and unchanged.

## Not included

- Production Jellyfin backup, restore, scheduling, upgrade or service changes.
- Media-original backup; the Jellyfin archive preserves application state and mappings only.
- Encryption, off-host transport, owner recovery-key custody or retention automation.
- Representative media, public clients, concurrency or remote-access testing.
- Transcoding, GPU use or acceleration enablement.

Release requires repository, Phase 4/5/6, publication, complete regression and whitespace validation on the exact commit.
