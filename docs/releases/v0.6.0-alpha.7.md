# v0.6.0-alpha.7 — Nextcloud encrypted off-host recovery candidate

Seventh bounded Phase 5 prerelease. **Phase 5 is not complete and production Nextcloud is not adopted.**

## Included

- Nextcloud Restic 0.19.1 vault with reviewed Windows/Linux amd64 archive and executable checksums.
- Separate operational and recovery key paths; plans and logs exclude key material.
- Encrypted snapshot storage, complete repository data-pack checks, local decryption verification and a portable recovery manifest.
- Fresh Nextcloud recovery using unrelated containers, volumes, database credentials, root and port.
- Exact WebDAV fixture verification before backup, after recovery and after a recovered-project stop/start cycle.
- Restore-gated 7 daily / 4 weekly / 3 monthly retention planning and application.
- Manual two-runner workflow with immutable artifact actions, encrypted-only transfer and an independently injected test key.
- Focused vault tests and expanded Phase 5 validation for the recovery contract, workflow and Restic tool manifest.

## Release decision

Go for `0.6.0-alpha.7` only after the standard cross-platform matrix and both jobs of the Nextcloud off-host recovery workflow pass on the exact commit. No-go for stable `0.6.0`, production migration or replacement of the owner's backup process.

## Boundaries

The clean-runner gate uses generated non-personal WebDAV content in an expiring synthetic Restic repository. It does not provide durable off-host storage, migrate personal data, prove the owner's real offline-key custody, cover external storage, native clients, collaboration, representative scale or upgrades.

The existing personal Nextcloud deployment remains outside this adapter. No personal users, files, credentials, shares, application settings or database rows are read, exported or changed.

## Next gate

Production adoption remains a separate owner decision requiring explicit storage paths, durable off-host destination, independent key custody, scheduling, retention ownership and a real-data recovery rehearsal. No later Phase 5 service begins without a separate command.
