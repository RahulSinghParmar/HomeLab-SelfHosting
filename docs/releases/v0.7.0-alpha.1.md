# v0.7.0-alpha.1 — Phase 6 media safety foundation

This prerelease starts Phase 6 with a non-activating storage, workload and acceleration contract.

## Included

- An exact Immich 3.3.5 server/ML/Valkey/PostgreSQL release set pinned by SHA-256 digest.
- A strict authoritative/derived/cache media classification that cannot treat originals as disposable.
- Manual-by-default thumbnail, OCR, recognition, indexing, scan and transcode jobs.
- Bounded component resource ceilings totaling no more than 6 GiB.
- A privacy-filtered read-only host audit and deterministic disabled plan.
- CPU fallback when hardware, driver, runtime or synthetic testing is incomplete.
- Reference-host evidence showing why the GT 730/391.35 combination cannot satisfy current Immich CUDA requirements.

## Not included

This release does not deploy Immich, select media-management applications, adapt Jellyfin, enable a GPU, run a transcode, inspect production media or change Docker settings. It is an early bounded Phase 6 prerelease, not a production media-stack release.
