# v0.6.0-alpha.1 — Paperless-ngx recovery candidate

First bounded Phase 5 prerelease. **Phase 5 is not complete and no production application is adopted.**

## Delivered

- Digest-pinned Paperless-ngx 3.2.1, PostgreSQL 18 and Valkey 9 in a fresh loopback-only three-service project.
- Private generated credentials, internal database/broker network, six owned volumes, resource ceilings, health checks, confirmation tokens and drift-aware lifecycle.
- Nonempty synthetic upload, searchable text, metadata edit and exact original-file checksum exercise.
- One application-write consistency boundary covering the supported document exporter, semantic inventory, PostgreSQL custom dump and data/media/export snapshots.
- Sensitive manifest with exact versions, consistency completion, credentials/configuration/database hashes and per-file checksums.
- Independent exporter/importer recovery into new volumes plus semantic equality and restart-persistence checks.
- Operator guide, Windows Docker Desktop validation record, 10 focused unit tests and an offline release-surface validator.

## Release decision

Go for `0.6.0-alpha.1` as an experimental Paperless recovery module. No-go for stable `0.6.0`, production migration, backup replacement or completed personal-data recovery.

The existing Paperless services were healthy during read-only inspection, but all discovered backup reports represented a zero-document library. They remain outside this adapter and were not changed.

## Remaining work

The local snapshot is plaintext-sensitive. Restic is the selected candidate for encrypted cross-platform storage, but download/installation, separate recovery-key custody, off-host repository, `check`, retention and restore are not part of this release. Upstream exporter restores omit API tokens and require compatible Paperless versions. Production data, authentication/public access, mail ingestion, populated-library load, upgrades, cross-platform Docker runtimes and hardware-failure recovery remain unverified.

Phase 5 continues one application at a time: Paperless encrypted recovery boundary, then AFFiNE, Nextcloud, Firefly III, Vaultwarden and Karakeep only after separate review.
