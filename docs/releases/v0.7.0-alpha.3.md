# 0.7.0-alpha.3 — Immich encrypted off-host recovery

Date: 2026-11-03

## Included

- Checksum-pinned Restic 0.19.1 validation for Windows and Linux amd64.
- Separate operational and recovery-key file references with private-file checks and secret-free plans/output.
- Encrypted storage of only verified Immich PostgreSQL/protected-original recovery sets.
- Complete repository-data checks, exact decrypted manifest validation and restore-protection tagging.
- Portable nonsecret recovery manifests and source-state-independent recovery planning.
- Restore-gated `7 daily / 4 weekly / 3 monthly` retention with non-destructive preview.
- A two-runner hosted workflow that transports only the encrypted repository and injects the recovery key independently.
- Fresh Immich application restore, exact original download and stop/start persistence checks.
