# 0.8.0-alpha.2 — Matrix identity and recovery foundation

This prerelease extends Phase 7 with an identity-safe Matrix/Synapse core and an application-aware synthetic recovery proof.

## Included

- Immutable multi-architecture Synapse `1.164.2`, PostgreSQL `15.19` and Element Web `1.12.35` image identities.
- A loopback-only Compose renderer with a private database network, file-backed database secret, resource ceilings, health checks and bounded logs.
- Explicit preservation of `server_name`, server signing key, PostgreSQL, media and Element configuration.
- A synthetic account/room/text/media exercise followed by quiesced backup, source removal and independent-root restore.
- Validation that a second login can recover the exact room event and media bytes with the unchanged signing key.
- Honest separation of homeserver recovery from client E2EE recovery.

## Not included

- Production Matrix migration, restart, image update or state adoption.
- Production encrypted/off-host backup or recovery certification.
- Fresh-device Element E2EE-key recovery.
- Federation, TURN/call, bridge or admin-UI enablement and validation.
- Coolify or native Windows startup/reboot work.
- Phase 7 stable-release closure.

This is a prerelease. Continue with owner-validated E2EE and optional-network decisions before production adoption; then proceed to the Coolify and Windows lifecycle modules.
