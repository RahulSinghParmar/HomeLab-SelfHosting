# v0.6.0-alpha.5 — AFFiNE browser and encrypted off-host recovery candidate

Fifth bounded Phase 5 prerelease. **Phase 5 is not complete and production AFFiNE is not adopted.**

## Included

- Digest-pinned Playwright 1.64.0/Chromium browser image built from a package-lock-controlled validation driver.
- Rendered sign-in, synced-workspace creation, note editing, title/paragraph checks, reload persistence and an independent browser session.
- Browser evidence repeated after source restart, fresh PostgreSQL/config/storage restore, recovered application restart and recovered project stop/start.
- Windows-safe private evidence streaming, collision-free repeated recovery proofs and automatic disposal of synthetic containers, networks and volumes.
- AFFiNE Restic 0.19.1 vault with exact Windows/Linux amd64 checksums, separate key custody, full-data checks, portable manifests, off-host recovery plan and restore-gated 7/4/3 retention.
- Manual two-runner workflow with immutable artifact actions, encrypted-only transfer and independently injected test key.
- Focused regression tests and expanded Phase 5 validation for browser, vault, workflow and image contracts.

## Release decision

Go for `0.6.0-alpha.5` only after the standard cross-platform matrix and both jobs of the AFFiNE off-host recovery workflow pass on the exact commit. No-go for stable `0.6.0`, production migration or replacement of the owner's backup process.

## Boundaries

The browser check covers the declared synthetic title and paragraph, not all AFFiNE blocks or clients. Native desktop/mobile sync, attachments, comments, public access, SMTP, OAuth, AI, indexing, concurrent editing, representative scale and upgrades remain unverified. The hosted encrypted repository is short-lived synthetic evidence, not durable owner backup storage or proof of real offline-key custody.

The existing personal AFFiNE deployment remains outside this adapter. No personal users, notes, credentials, files or database rows were read, exported or changed.

## Next gate

After this AFFiNE recovery substage, Phase 5 may proceed to Nextcloud only after an explicit separate command. Production AFFiNE adoption remains a separate decision requiring owner paths, durable destinations, key custody, scheduling and a real-data rehearsal.
