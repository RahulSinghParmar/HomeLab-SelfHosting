# 0.7.0-alpha.6 — Jellyfin encrypted application and media recovery

Date: 2026-11-11

## Included

- A strict recovery-set contract that binds Jellyfin's application-aware archive and one separately owner-managed media original.
- Checksum-pinned Restic 0.19.1 identities for Windows and Linux amd64.
- Separate operational and recovery-key custody, encrypted-only transport and a tamper-evident portable manifest.
- Complete repository-data checks before and after source loss.
- Source application/media/key deletion followed by clean same-version restore using recovery material only.
- Byte-exact direct play before backup, after recovery and after recovered-instance restart.
- Reusable CLI validators, focused contract tests and a confirmation-gated Windows rehearsal tool.

## Reference result

The Windows rehearsal passed all application, encryption, media, restart and isolation gates. The production native Jellyfin service remained `Running`, `Automatic` and `Healthy`. Disposable trial repositories and keys were removed; only sanitized evidence remained outside Git.

## Not included

- Production Jellyfin backup, restore, scheduling, retention execution, upgrades or service changes.
- An adopted physical off-host destination or real offline recovery-key location.
- Representative production media, public clients, concurrency or remote-access testing.
- Transcoding, GPU access or acceleration enablement.

Release requires repository, Phase 4/5/6, publication, complete regression and whitespace validation on the exact commit.
