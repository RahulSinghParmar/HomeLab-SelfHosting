# v0.6.0 — Phase 5 encrypted recovery kit

Version 0.6.0 completes the bounded Phase 5 recovery-toolkit milestone for six personal-data applications. Each module now has an application-consistent backup, encrypted portable repository, separate recovery-key path, full-data check, restore-gated retention and an independent clean-runner restore of nonempty synthetic content.

## Included

- Paperless-ngx document import and restart recovery.
- AFFiNE rendered workspace-note recovery across reload and independent sessions.
- Nextcloud exact WebDAV content and restart recovery.
- Firefly III finance transaction, attachment and export recovery.
- Vaultwarden decrypted secure-note and attachment recovery.
- Karakeep bookmark, asset and rebuilt-search recovery.
- One final machine-readable closure contract for consistency methods, authoritative material and semantic proof fields.
- A common Restic 0.19.1 encryption/full-check contract and restore-gated `7/4/3` retention policy.
- A manual integrated workflow that reruns all twelve prepare/recover jobs on the exact release commit.

## Release gate

Publish only after the standard six-job validation matrix and the manual twelve-job Phase 5 integrated recovery review pass on the exact commit. Do not move or reuse the tag.

## Scope boundary

Stable `0.6.0` means the public synthetic recovery-toolkit contract is complete and regression-tested. It does not mean a particular owner's production backup deployment is active. Owner storage, keys, schedules, notification credentials and personal-data restore evidence remain outside Git and require separate approval.
